# 🏓 VOLTEX — Table Tennis Live Intelligence

> **Built exclusively for Table Tennis.** AI-powered live match intelligence dashboard featuring real-time tactical analysis, player telemetry, win probability tracking, and an interactive prediction game — all synchronized with a live YouTube stream.

## 🎯 What is VOLTEX?

**VOLTEX** is a premium, Apple-style sports intelligence broadcast experience built for **Table Tennis fans, analysts, and coaches**. Paste any ITTF or table tennis YouTube stream link and let Google Gemini AI power your viewing experience.

This project was built for the **Google AI Hackathon** and is powered by the **Google Gemini API**.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🎥 **Live Stream Sync** | Paste any Table Tennis YouTube URL — auto-detects players, tournament, and match context using Gemini AI |
| 🧠 **AI Tactical Commentary** | Real-time tactical insights generated by Gemini 2.5 Flash, synced to the video timestamp |
| 🔊 **Audio Commentary** | Optional text-to-speech mode — let the AI narrate the match out loud |
| 📊 **Live Telemetry** | Animated win probability bars and rally aggression meters that pulse in real time |
| 🏆 **XP Prediction Game** | Predict who scores the next point, earn XP, build streaks, unlock rank badges (Rookie → Legend) |
| 📱 **Fully Responsive** | Works on mobile, tablet, and widescreen |
| 🎨 **Premium UI** | Glassmorphism design, smooth animations, dark mode support |

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- A [Google Gemini API Key](https://ai.google.dev/)

### Run Locally

```bash
# Install dependencies
npm install --no-bin-links

# Start dev server
node ./node_modules/next/dist/bin/next dev --turbopack
```

Open [http://localhost:3000](http://localhost:3000).

Enter your Gemini API key in the header field, paste a Table Tennis YouTube URL, and click **Sync Stream**.

## 🐳 Deploy to Google Cloud Run

```bash
# Build & push Docker image
gcloud builds submit --tag gcr.io/YOUR_PROJECT_ID/voltex

# Deploy to Cloud Run
gcloud run deploy voltex \
  --image gcr.io/YOUR_PROJECT_ID/voltex \
  --platform managed \
  --region us-central1 \
  --allow-unauthenticated \
  --port 3000
```

## 🔑 Environment

The Gemini API key is entered at runtime via the UI. For production deployments, set it as a Cloud Run environment variable:

```bash
gcloud run deploy voltex --set-env-vars GEMINI_API_KEY=your_key_here ...
```
